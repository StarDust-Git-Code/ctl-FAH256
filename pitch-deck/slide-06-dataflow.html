Server-Side Verification

function verifyPacket(packet, deviceSecret) { // 1. HMAC verification const expectedHmac = hmacSha256(deviceSecret, packet.payload) if (!timingSafeEqual(packet.hmac, expectedHmac)) throw new Error('HMAC mismatch') // 2. Hash chain verification const computedHash = sha256( packet.payload + packet.prev_hash ) if (computedHash !== packet.prev_hash) throw new Error('Hash chain broken') // 3. Replay protection (EID) if (await redis.sismember('eids:seen', packet.eid)) throw new Error('Replay attack detected') await redis.sadd('eids:seen', packet.eid) await redis.expire('eids:seen', 86400) // 24h TTL return true }

Attack Vectors Mitigated

✗ Temp Falsification

Attacker modifies temp in transit → HMAC fails → Rejected

✗ History Rewriting

Insert/delete readings → Hash chain breaks → Detected

✗ Replay Attack

Resend old packet → EID in Redis set → Rejected

✗ Device Cloning

Extract key from one box → Secure element prevents readout

⚠ Network Jamming

Box offline → Local buffer (500 reads) → Sync on reconnect

⚠ Battery Death

Last reading includes battery % → Alert before loss
