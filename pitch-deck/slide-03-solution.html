Proposed Solution

End-to-end cold-chain integrity without blockchain complexity

ColdChain Guardian Platform

A lightweight, demo-ready architecture delivering real-time monitoring, cryptographic data integrity, and digital chain-of-custody — all without blockchain overhead.

✓ Real-time temperature & tamper sensing ✓ HMAC-SHA256 packet authentication ✓ SHA-256 hash chain integrity ✓ EID-based replay protection ✓ QR-based driver handoffs ✓ Live dashboard with integrity status

Hardware

ESP32 + DS18B20 + MPU6050 inside cargo box. Continuous monitoring, signed packets, local buffering.

Backend

Node.js API verifies HMAC, validates hash chain, dedups EIDs, stores verified data. REST endpoints for all consumers.

Apps & Dashboard

Cargo Services App for drivers (QR handoffs), React dashboard for monitors. Live tracking, alerts, custody timeline.

No blockchain. No IPFS. No Polygon. Just cryptography that works.

Lightweight • Verifiable • Demo-Ready
